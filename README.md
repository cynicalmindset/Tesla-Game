## 🏎️ Key Features

- **SpaceX Cold-Gas Thrusters**: Underbody thrusters deliver vertical lift-off from standstill or at speeds exceeding 450 km/h.
- **Aerial Stunt Physics**: Perform 360° front/back flips (<kbd>F</kbd>), barrel rolls (<kbd>X</kbd>), flat spins (<kbd>C</kbd>), and mid-air attitude maneuvers.
- **Dynamic Martian Environment (Mars Mode)**: Press <kbd>P</kbd> or click the Mars toggle to simulate driving on Mars—1/3 Earth gravity (3.72 m/s²), red Martian sky, Phobos celestial orb, and swirling dust storms.
- **Responsive Regenerative Braking**: High-performance anti-lock regenerative braking (<kbd>S</kbd> / <kbd>Down Arrow</kbd>) with tire screech audio synthesis.
- **Realistic Crash Damage & Fire Tracking**: High-speed collisions cause chassis crumple, paint scorching, grinding friction sparks, billowing dark smoke, and dynamic fire particles with real-time firelight casting.
- **Interactive Missions System**: Objective checklist tracking speed trials, flyovers over Cybertruck and Semi traffic, ring collections, and standing thruster flips.
- **Clean Apple-Inspired HUD**: Minimalist liquid glass aesthetic with dynamic island stunt alerts, digital speedometer, cold-gas tank meter, and mobile-responsive controls.
- **Procedural Web Audio Engine**: Zero-asset, fully synthesized electric powertrain whir, rocket thruster roars, aerodynamic wind rush, tire skid screeches, and fire rumble.

## 🎮 Controls

### Desktop Keyboard
| Key | Action |
| --- | --- |
| <kbd>W</kbd> / <kbd>↑</kbd> | Accelerate / Air Pitch Down |
| <kbd>S</kbd> / <kbd>↓</kbd> | Regenerative Brake / Air Pitch Up |
| <kbd>A</kbd> / <kbd>←</kbd> | Steer Left / Air Roll Left |
| <kbd>D</kbd> / <kbd>→</kbd> | Steer Right / Air Roll Right |
| <kbd>Space</kbd> | Cold-Gas Rocket Thruster Jump |
| <kbd>F</kbd> | Instant 360° Flip Stunt |
| <kbd>X</kbd> | Instant 360° Barrel Roll |
| <kbd>C</kbd> | Instant Flat Spin |
| <kbd>Shift</kbd> | Capacitor Boost |
| <kbd>P</kbd> | Toggle Mars Flight Mode (1/3 Gravity) |
| <kbd>M</kbd> | Toggle Missions Checklist Drawer |
| <kbd>R</kbd> | Quick Restart Run |
| <kbd>Esc</kbd> | Pause Game |

### Mobile Touch Controls
- Dedicated on-screen thumb clusters automatically active on mobile devices and tablet viewports.
- Large center **JUMP** thruster button, haptic feedback pulses, and stunt shortcuts.
